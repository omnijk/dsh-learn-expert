# 学习专家 · AI 私教（dsh-learn-expert）

说出想学什么，或丢进来一份资料，它就开讲——像真人老师一样，一节一节带你走，直到你真懂。

## 教学流程

1. **备课与摸底**：你给了资料（书、讲义、视频、代码仓库），先读完再开讲；没给资料会先自行调研核对。开讲前先用几个选项卡问题摸清你的背景、基础与目标。
2. **章节路线图**：根据摸底结果生成章节式路线图，已会的章节直接跳过；学习中暴露新盲区会动态补节点。
3. **逐节教学**：每次回复只讲一小段，随后出一道题——要么考验刚讲的内容，要么顺势引入新知识点。答错不直给答案，顺着你的思路找出矛盾；讲不懂就换类比、反例或图示重讲。
4. **随时打断**：讲到一半没跟上，随时提问，老师先回答你，再接着刚才的地方讲。
5. **节末确认**：一节讲完、确认没有疑问后，给出本节核心总结卡片，并在同一轮对话里自然衔接下一节。掌握度（准确性/深度/迁移/辨别四维）达到解锁线才推进。
6. **易错点记录**：反复出错与易混淆的知识点自动记入你的画像，后续讲解与出题针对性覆盖。
7. **笔记与召回**：每节学完整理一页笔记（优先用你自己的话）；按遗忘曲线（SM-2）在合适时机叫你回来复习，以主动回忆为主。

## 课堂（左侧边栏入口）

- 今日首页：按时间问候，「想弄懂点新东西？」输入入口；「继续学习」卡片显示当前课程分段进度、正在学的章节与上次学习时间，一键回到课堂。
- 课程列表：每门课程一张卡片（分段进度条、掌握/重学/复习计数、当前在学节点），悬停出现收藏星标、「随手问」（跳回该课程的教学会话）与「⋯」菜单（重命名 / 移动到分组 / 锁定 / 删除）。
- 筛选与搜索：全部 / 收藏 / 在学 / 待复习 / 已学完 / 书房（分组），支持按课程名与知识点搜索。
- 课程仪表盘：「学习旅程」逐节点展示掌握状态（已掌握=绿色对号、当前节=序号徽标、未解锁=灰色锁），每个节点可展开笔记（老师结课笔记）、导图（课程知识结构图）、手记（自己的随堂笔记，可编辑保存）；「复习巩固」列出到期复习项与即将到来的复习时间。全部掌握时显示撒花庆祝横幅。
- 复盘面板：跨课程汇总 SM-2 到期复习项；每个到期知识点支持费曼复述（用自己的话讲一遍并存为手记），可一键跳回对应会话复习。
- 对话内庆祝卡片：节点评分解锁时工具卡片变为彩色渐变卡并撒花，课程完成时撒花加倍。
- 顶部「今日 / 课堂 / 复盘 / 分析」页签可随时切换。

## 分析面板（左侧边栏入口）

- 统计卡：学习计划数、已掌握章节、平均掌握度、待复习数
- 掌握进度折线图：每个学习计划一条阶梯线
- 路线图结构图：概念节点按依赖分层，颜色表示状态，悬停看四维分
- 学习热力图：最近数周的学习活动密度（摸底、评分、作答、复习）
- 教学质量：每节点平均作答轮数、复习通过率
- 多学习者切换、数据一键导出

## 画像与隐私

学习数据按学习者（`learn-<learnerId>/`）沉淀在当前工作区的 `dsh-learn/` 文件夹（JSON/Markdown，可直接查看）。画像可通过工具、插件详情页卡片查看/编辑；`ai_learn_export` / `ai_learn_import` 支持备份与迁移，面板也可一键导出。

## 按需激活（v1.2.3）

启用插件不等于给每个会话都注入私教上下文。14 个 `ai_learn_*` 工具只在「这个会话确实要学东西」时才会被声明：

- 判定时机是每一步的工具准备阶段（`ctx.tools.register(tool, { when })`，条件是纯函数，不改注册、不启动工具）；
- 触发条件：用户消息里出现明确的学习意图措辞；或 `learn-expert` 技能被加载（技能正文带 `<skill_content name="learn-expert">` 标记，随消息一起进入会话）；或复习到期的系统提醒；
- 实时事件通过 `session/event` 观察；恢复的历史会话（seed 事件不会重放）在第一次判定时用 `session.deriveMessages()` 一次性回看；
- 命中后在该会话内保持开启（课程跨多轮），未命中的会话完全看不到这些工具。

## 依赖与边界

- 教学内容质量依赖当前模型；评分与追问由 `learn-expert` 技能协议约束。
- 提醒按 24 小时冷却触发（`reviewReminder` 可配置）。
- 工具卡片与分析面板只在 DSH Web GUI 呈现。

## 稳定性（v1.2.1）

- 课程接口的 `learnerId`/`roadmapId`/`nodeId` 全部走白名单校验与安全路径拼接，越界直接 400；不再能用 `../..` 读写学习目录之外的文件。
- 插件 API 拒绝跨站请求（403），POST 必须是 `application/json`（415），请求体上限 1 MiB（413）。
- 单个损坏的 JSON 会被隔离成 `*.corrupt-<时间戳>` 并回退默认值，不会让整个面板 500；写入是 tmp + fsync + rename 原子替换。
- 所有「读-改-写」在同一学习目录内串行执行，多个会话同时评分不再互相覆盖。
- 掌握度有状态门禁：锁定节点不能跳过、前置未掌握不能解锁，`passed` 只接受真正的布尔值。
- 面板渲染包了错误边界：单个组件出错只显示可重试的提示，不会让整个侧边栏白屏。
- 已掌握的节点不会被一次误评分静默降级（复习失败才是回到重学的入口）；课程两次答错进入 `REMEDIATING` 后，答对一题即回到正常教学。
- slug 规则、轮询逻辑各只有一份实现（`src/store/slug.js`、`useLoadPoll`），避免同类改动只落到其中一个面板。

## 全景导图（v1.2.2）

课程详情里的「全景导图」是一张横向思维导图：课程主题作根节点，概念节点按教学顺序自上而下排成一列，状态由左侧圆环颜色表达。

布局有三条硬约束，写在 `client.js` 的 `DagChart` 里：

1. 根节点与文字列之间保留固定的 `GUTTER`，曲线两个控制点都被限制在它内部，因此曲线水平离开根、水平进入标签，不会横穿文字；
2. 每行固定行高，标题与副标题都用 canvas `measureText` 按真实字宽测量后截断加省略号，既不出右缘也不侵入相邻行；
3. 行末不再有状态圆点（旧实现会落进更长的副标题中间）——状态只由左侧圆环颜色表达。

`.probe/render-dag.mjs` 会把真实的 `DagChart` 与真实课程数据搬到浏览器里跑一遍（同一条 canvas 测量路径），输出几何审计 `maxTextRight / fits / overlaps`，用于防止布局回归。
